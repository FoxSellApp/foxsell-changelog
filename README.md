# FoxSell Changelog

Public-facing changelog site for FoxSell, built with Next.js using the pages router.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

This repository is ready to connect to Vercel.

## Updating the changelog

Add or edit merchant-facing entries in `pages/index.js`.
Keep updates focused on meaningful shipped improvements and avoid internal implementation details.
